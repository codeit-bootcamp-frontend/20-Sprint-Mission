# 🐼 스프린트 미션 (판다 마켓)

## 🚀 기본 요구사항

### 1. URL Path
| 경로 | 설명 |
|------|------|
| `/` | 랜딩 페이지 |
| `/login` | 로그인 페이지 (빈 페이지) |
| `/items` | 아이템 페이지 (빈 페이지) |
| `/privacy` | Privacy Policy 페이지 (빈 페이지) |
| `/faq` | FAQ 페이지 (빈 페이지) |

---

### 2. 레이아웃 규칙
- **1920px 이상**
    - 배경색(하늘색)은 화면 너비 전체를 채움
    - 내부 요소(로고, 버튼)는 고정된 위치 유지
    - 여백만 늘어남
- **1920px 미만**
    - `"판다마켓"` 로고: **왼쪽 여백 200px**
    - `"로그인"` 버튼: **오른쪽 여백 200px**
    - 화면이 줄어들수록 두 요소 사이의 거리가 점점 좁아짐

---

### 3. 클릭 이벤트
- **로고 (`판다마켓`)** → `/`
- **로그인 버튼** → `/login`
- **구경하러가기 버튼** → `/items`
- **Privacy Policy** → `/privacy`
- **FAQ** → `/faq`
